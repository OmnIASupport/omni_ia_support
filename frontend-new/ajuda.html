O que é o Omni IA Support?

É uma proposta de plataforma de acessibilidade voltada a facilitar a comunicação entre pessoas surdas e ouvintes, com recursos relacionados a Português e Libras.

Como acesso a tradução?

Use a opção “Traduzir” no menu ou selecione o botão abaixo para abrir a página de tradução.

Acessar tradução
Posso usar o chat para pedir ajuda?

Sim. Abra a página Chat para acessar a área de conversas disponível no projeto.

Abrir o chat
O que faço se não aparecer meu nome no cabeçalho?

Confira se você entrou na sua conta. Se o problema continuar, saia e entre novamente. A exibição do nome depende dos dados salvos pelo sistema de login.
