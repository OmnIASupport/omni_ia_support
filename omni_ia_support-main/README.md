# Omni IA Support
A Omni IA Support foi criada visando aumentar a acessibilidade e melhorar a comunicação para deficientes auditivos e ouvintes que convivem em seu dia a dia. Para que isso aconteça, nossa equipe tem o foco de desenvolver um sistema inteligente, que faça uma tradução bidirecional para ambas as linguagens, tanto para a Língua portuguesa quanto para a Língua Brasileira de Sinais (Libras), por meio de uma Inteligência Artificial 3D (Avatar) que ajudará nossos usuários em qualquer diversidade que apareça.
Além disso, colocaremos recursos de traduções via áudio ou texto para os usuários ouvintes, dando uma maior amplitude para a comunicação, podendo agregar todos a um único mundo.
